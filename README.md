# MIND Privacy

Repositório público de documentos de privacidade do **MIND**, extensão Chrome local-first para notas, links, backlinks, grafos, mapas mentais, captura Web e sincronização online opcional.

## Política de Privacidade

A política oficial está disponível em:

- [PRIVACY.md](./PRIVACY.md)

Versão atual: **20 de setembro de 2026**.

## URL pública

Para cadastros que exigem uma URL pública de política de privacidade, utilize:

https://github.com/marcosmurilorodriguesb-alt/MIND-privacy/blob/main/PRIVACY.md

O arquivo `index.html` contém a mesma política em formato de página e pode ser publicado por GitHub Pages quando esse recurso estiver habilitado para o repositório.

## Escopo

Este repositório contém apenas documentação pública de privacidade e não armazena dados de usuários do MIND.

Para dúvidas, uma Issue pode ser usada sem incluir senhas, tokens, conteúdo privado de notas ou outros dados sensíveis.
