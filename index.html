Política de Privacidade — MIND

Última atualização: 20 de setembro de 2026

Esta Política de Privacidade descreve como a extensão MIND trata dados quando você usa notas, organização local, captura de páginas e recursos online opcionais.

1. Princípio local-first

O MIND foi projetado para funcionar principalmente de forma local-first. Notas internas, metadados e índices locais podem ser armazenados no navegador usando IndexedDB. Preferências, sessões e dados temporários podem ser armazenados pelos mecanismos locais do Chrome. Conteúdo mantido apenas em áreas locais não é enviado a um servidor apenas por existir no MIND.

2. Dados tratados localmente

  • conteúdo, títulos e caminhos de notas;
  • pastas e raízes;
  • links internos, backlinks, tags, headings e metadados derivados;
  • preferências de interface e organização;
  • dados necessários para busca, grafo e mapas mentais;
  • dados de sessão necessários para recursos online opcionais.

3. Captura de páginas e seleções

Quando você solicita explicitamente uma captura, o MIND pode acessar a guia ativa para obter título, URL, descrição, texto selecionado e conteúdo textual necessário à captura. A captura usa acesso temporário à guia ativa e não concede acesso persistente a todos os sites. O MIND não monitora continuamente seu histórico de navegação.

Conteúdo capturado permanece local quando salvo em uma área local. Se o usuário escolher uma raiz online como destino, o conteúdo correspondente poderá ser enviado ao Supabase como parte da sincronização solicitada.

4. Permissões do Chrome

O MIND utiliza storage, sidePanel, contextMenus, scripting e activeTab. A permissão identity é opcional e solicitada somente quando o usuário inicia autenticação Google. O MIND não solicita acesso persistente a todos os sites para realizar a captura Web.

5. Conta por e-mail e senha

Quando o usuário escolhe autenticação por e-mail e senha, esses dados são transmitidos por HTTPS diretamente ao Supabase Auth. O MIND não grava a senha em IndexedDB nem em chrome.storage.local. Após autenticação, informações da conta e tokens de sessão podem ser armazenados localmente para manter a sessão ativa.

6. Conta Google

Quando o usuário escolhe autenticação Google, o MIND solicita a permissão opcional identity e usa o fluxo de autenticação do Chrome/Google. O fluxo pode solicitar openid, email e profile. O ID Token e informações de perfil associadas são usados para autenticar ou vincular a conta no Supabase Auth.

O pacote da extensão não contém Google Client Secret nem chave service_role do Supabase.

7. Sessão online

Para manter a conta conectada, o MIND pode armazenar localmente access token, refresh token, data de expiração, identificador e informações básicas do usuário e provedores/identidades vinculados. Esses dados são usados para autenticar chamadas ao backend e restaurar a sessão. Sair da conta remove a sessão local mantida pelo MIND.

8. Sincronização online opcional

Quando você usa uma raiz online, dados dessa raiz podem ser enviados ao Supabase, incluindo identificador da conta, nome da raiz, caminhos de pastas, caminhos e títulos de notas, conteúdo das notas online, posição e datas de criação/atualização. O banco utiliza Row Level Security (RLS) para restringir registros ao usuário autenticado correspondente.

Notas e raízes mantidas apenas localmente não são convertidas automaticamente em conteúdo online.

9. Serviços de terceiros

O MIND pode utilizar Google para autenticação opcional, Supabase para autenticação e sincronização online opcional e Google Chrome/Chrome Web Store para execução e distribuição. Esses fornecedores possuem políticas próprias.

10. Analytics, publicidade e venda de dados

A versão descrita nesta política não inclui publicidade comportamental nem sistema próprio de analytics destinado a rastrear a atividade do usuário. O MIND não vende dados pessoais e não utiliza notas, capturas, credenciais ou dados de autenticação para publicidade personalizada.

11. Uso Limitado de dados

O uso de informações recebidas das APIs do Google pelo MIND cumprirá a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).

Os dados são utilizados somente para fornecer ou melhorar funcionalidades do MIND iniciadas ou habilitadas pelo usuário. Eles não são transferidos para terceiros para publicidade, criação de perfis publicitários ou finalidades incompatíveis com a funcionalidade declarada, exceto quando necessário para prestar o serviço solicitado, cumprir a lei ou proteger contra abuso e incidentes de segurança.

12. Retenção e exclusão

Dados locais permanecem no dispositivo até serem removidos pelo usuário, pela extensão, pelo navegador, pela desinstalação/limpeza de dados da extensão ou por operações de exclusão disponíveis no MIND. Conteúdo online permanece no Supabase enquanto estiver associado à conta e não for excluído.

Desinstalar a extensão ou sair da conta não significa exclusão automática da conta online ou de todo conteúdo remoto.

13. Segurança

O MIND utiliza armazenamento local, HTTPS, autenticação para recursos online, políticas RLS no banco, evita incluir segredos administrativos no pacote e usa acesso temporário à guia ativa para captura. Nenhum sistema pode garantir segurança absoluta.

14. Crianças

O MIND não é projetado especificamente para coletar dados de crianças e não utiliza recursos direcionados a publicidade infantil.

15. Alterações nesta política

Esta política pode ser atualizada quando houver alterações relevantes nas funcionalidades, integrações, permissões ou práticas de tratamento de dados. A data de atualização será alterada quando houver uma nova versão.

16. Contato

Para dúvidas sobre privacidade, utilize o repositório público MIND-privacy. Você pode abrir uma Issue para solicitar esclarecimentos. Não publique senhas, tokens, conteúdo privado de notas ou outros dados sensíveis em uma Issue pública.
